# Saga 0.5.0-beta.1 - "Svelte" Release Notes

Saga `0.5.0-beta.1`, code-named **Svelte**, is the first beta. This update focuses on the places you spend time browsing and editing lore. You’ll find the same controls and workflows in the Library, Loredeck Workbench, and Deck Maker.

Last updated November 7, 2026.

## Compatibility

- Requires SillyTavern `1.12.0` or later.
- Update manually from the repository. Automatic updates are disabled for this beta (`auto_update: false`).
- On a fresh install, open Saga from the Extensions menu.

## What's New

- **Lighter Library browsing.** Bundled Loredeck covers use smaller images when they appear as thumbnails. Open a deck's details to see its full-size cover.
- **Smoother Lorecard selection.** The Lorecards tab of the Loredeck Workbench now uses Svelte. Once a deck is open, Saga can update the rows that changed while keeping the rest of the list in place.
- **Deck files load together.** Saga can read several entry files at once when opening a deck stored in multiple files. Cards and Pack Health results still follow the same order.
- **A lighter start for Deck Maker.** Closed sections wait until you open them to load their controls. Your projects and the order of the authoring steps stay the same.

## Since Scribe

- Lorecards saved without Context bounds stay that way. This fixes a case where otherwise eligible cards could be left out of the prompt. The [Lorecard Context Storage Patch](2026-11-05-lorecard-context-storage.md) explains which older cards Saga can repair automatically.
- This beta also includes the earlier reliability fixes for saving, switching chats, and recovering interrupted work. See the [October reliability patch notes](2026-10-06-reliability-patches.md).

## Beta Notes

- The first Workbench open can take longer than it did in Scribe, even though selecting cards once the deck is open takes less work. If you notice a pause, tell us which deck you opened and whether it happened on the first open or while working in the deck.
- Unsupported old imported state schemas are rejected. See [Storage and State Safety](../user/STORAGE_AND_STATE_SAFETY.md) for backups and recovery.
